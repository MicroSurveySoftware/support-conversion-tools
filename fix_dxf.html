Reg360 Orthoslice Repair Utility

Reg360 Orthoslice DXF Repair Utility

At the time this article is published, Register360 v2023.1.0 outputs Orthoslice files in a format that is not compatible with Map360 or AutoCAD because of how paths to external reference images are defined. This online utility was created to correct the paths.

  • 1. Locate the folder that contains orthoslice output files. This will consist of one DXF file with "Slice" in the name and one or multiple *.PNG files.
  •  

  •  
  • IMPORTANT! Create a backup copy of the DXF file using a different name.
  • 2. Open Windows Notepad
  • 3. Drag and Drop the original DXF file into Notepad
  •  

  •  
  • 4. Edit | Select All to highlight entire contents of file
  • 5. Edit | Copy:
  •  

  •  
  • 6. Right click in "DXF Input Field" at the bottom of this page and select "Paste"
  • 7. Submit
  • 8. The page that opens will contain the adjusted contents for the DXF file
  • 9. Left click inside the output window
  • 10. CTRL A to highlight contents
  • 11. CTRL C to copy contents
  • 12. Left click back in Windows Notepad
  • 13. Edit | Select All to highlight entire contents of file
  • 14. Edit | Paste to overwite contents of file
  • 15. File | Save
  • NOTE: Do not change the name of the DXF file when you save
  • 16. Use the Orthoslice import utility in Map360 to test the result
  • Please contact the support team if there are still issues with the orthoslice. Please provide a copy of the DXF file if possible.
